# Design system

Direction: calm dark-first interface with violet primary and mint success accent, rounded "bento" cards, large type, big touch targets, subtle spring press feedback. Light theme included; follows system by default.

| Token | Dark | Light |
|---|---|---|
| bg | #0F0B24 | #F6F4FF |
| surface / surface2 | #1A1538 / #251F4D | #FFFFFF / #ECE8FF |
| text / muted | #F4F2FF / #B3ADDB | #17123A / #585280 |
| primary | #8B6DFF | #5B3DF5 |
| accent (success) | #2EE6A6 | #0B8F63 |
| danger / warn | #FF6B8A / #FFB020 | #C81E4A / #B36B00 |

Type: system font. display 34/800, title 24/700, heading 18/700, body 16, label 14/600, caption 13. Spacing 4/8/12/16/24/32. Radius 10/16/24/pill. Minimum touch target 44-56 dp.
Components (`src/ui/index.tsx`): Screen, AppText, Card, Button, Chip, Segmented, ProgressBar, Ring, IconBadge, Row, Empty.
Accessibility: roles and labels on all controls, state never conveyed by colour alone (icons + text on correct/incorrect), live regions for feedback, text colours chosen for contrast (not yet audited with a tool).
Motion: spring scale on button press only. No continuous animation.
Brand: bolt-in-ring mark, generated by `tools/make_icons.py` (original artwork).
