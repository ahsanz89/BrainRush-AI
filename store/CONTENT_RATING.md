# Content rating questionnaire (IARC) — suggested answers

Play Console > Policy and programs > App content > Content rating. Answer honestly; the rating is issued by the rating authorities, not by us.

| Topic | Answer |
|---|---|
| Category | Game (or Reference/Education if you list as an app) |
| Violence / blood / fear | None |
| Sexual content / nudity | None |
| Profanity / crude humour | None |
| Controlled substances (drugs, alcohol, tobacco) | None |
| Gambling or simulated gambling | None |
| User-generated content or user interaction | None (no chat, no sharing) |
| Shares user location | No |
| Allows purchases of digital goods | No |
| Contains ads | No (in this version) |

Expected result: the lowest age band (Everyone / PEGI 3 / USK 0 style ratings). The final rating is decided by IARC.
